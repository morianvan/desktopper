# Desktopper v2.1.0

首个仓库发布版本，内置 Octane「蜘蛛热」桌宠。

## Windows 下载

下载 `Desktopper-2.1.0-windows-x64.zip`，完整解压后打开 `Desktopper/Desktopper.exe`。无需安装 Python，不能只移动 EXE。

## 功能

- 原生透明、置顶桌宠，支持拖动、自动活动、边缘转向、暂停和右键退出。
- Idle、Walk、Stim → Run，以及单次蝴蝶刀和跳板互动。
- 单次动作完整播放再接续；奔跑每次开始扎针一次，冲刺循环。
- 按姿态调整节奏与接续，减少移动中切换道具动作的突跳。
- 右键菜单调整 50%～200% 等比缩放，或 Ctrl＋滚轮；重启保留比例。
- `pets/` 目录及 `--config` 入口可接入其他角色；名称、素材、速度和播放序列独立配置。

## 验证与限制

28 项自动测试通过；原生窗口连续检查覆盖动作完成、接续、缩放、置顶透明和退出。打包后的 EXE 另行执行素材检查及限时启动检查。

当前保留用户提供的角色画面。节奏和帧序列已调整，但没有生成新的原画中间帧；部分源图跨格特效和缺少中间姿态仍限制流畅程度。
